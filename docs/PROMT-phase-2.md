# Задача: подключить движок преферанса к игровому столу (фаза 2)

Промт для новой сессии агента. Вставляется целиком.

## Роль и цель

Ты работаешь над «Преферанс клуб» — сетевым преферансом (Ленинградка) для игры
с друзьями: свой сервер (Docker Postgres + Next.js + Socket.IO) и веб-стол с
камерной атмосферой (свечи, сукно, фото-натюрморт). Лобби, чат, посадка за стол,
диалог правил и фото-натюрморт уже готовы. **Цель этой фазы:** заменить
декоративную раздачу на настоящую игру — раздача, торговля, прикуп, мизер,
висты, ходы и счёт на сукне, всё server-authoritative через Socket.IO.

## Что нужно сделать

1. **Протокол партии** — расширь `src/lib/protocol.ts`: полный снапшот состояния
   (`game:state`), события ходов (ставка/пас, прикуп, снос, мизер, вист, карта в
   взятку), уведомления о раздаче и результате раздачи. Именование событий —
   в стиле существующих (`room:state`, `chat:message`).
2. **Серверное состояние партии** — игровой сеанс в памяти на ключ стола
   (`src/server/`), поверх `round.ts`. Правила одного сервера:
   - **чужие руки никогда не уходят клиенту** — в снапшоте карты соперников
     заменены на количество;
   - сервер валидирует ходы через `legalMoves`, незаконный ход — отклонение с
     сообщением, а не падение;
   - переподключение/заход в середине партии → полный `game:state`;
   - зрители (`allowSpectators`) видят всё, но без действий;
   - сдающий ротируется по кругу (3 игрока за столом, 4-й сдаёт).
3. **Цифры правил** — сеанс создаёт `normalizeRuleset(Game.rules)`, подсчёт через
   `score.ts`; таблица пуля/гора/висты рисуется на сукне и обновляется после
   каждой раздачи. По закрытии пули или исчерпании лимита раздач — запись в
   `GameResult` и финальный экран мест.
4. **Клиент** — экраны фаз (торговля, прикуп/снос, мизер, висты, ход, результат
   раздачи) в стиле существующих панелей; своя рука — из своих карт через
   компоненты `src/components/cards/`; убрать декоративную раздачу и надпись
   «декоративная раздача — движок правил на следующем шаге».
5. **Тесты** — новые чистые функции (переходы сеанса, ротация сдающего, подсчёт
   за пулей с кастомными `Ruleset`) покрой тестами в стиле существующих.

## Конвенции

- Server-authoritative: клиент только предлагает действия.
- TypeScript strict, стиль как в соседних файлах (двусловные комментарии
  по-русски, без лишних абстракций), ESLint/TSC должны проходить чисто.
- Не добавляй зависимости без необходимости; ничего не переписывай «за компанию».
- Незакоммиченные изменения в репо — это работа предыдущих сессий, не откатывай их.

## Definition of Done

- `pnpm typecheck && pnpm lint && pnpm test && pnpm build` — без ошибок.
- `pnpm dev` на `:3005`: три вкладки-игрока садятся по ссылке, играется полная
  раздача от торговли до записи очков; чужих карт в network-трафике нет;
  перезагрузка страницы возвращает игрока в партию.
- Смоук-тест сокетов зелёный; скриншот стола после партии выглядит согласованно
  (свет, панели, счёт).
