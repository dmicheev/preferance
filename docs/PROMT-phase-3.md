# Задача: посадить за пустые места компьютер и выбрать уровень его игры (фаза 3)

Промт для новой сессии агента. Вставляется целиком.
Положить в репозиторий: `docs/PROMT-phase-3.md`.

## Роль и цель

Ты работаешь над «Преферанс клуб» — сетевым преферансом (Ленинградка) для игры
с друзьями: свой сервер (Docker Postgres + Next.js + Socket.IO) и веб-стол с
камерной атмосферой (свечи, сукно, фото-натюрморт). Лобби, стол, чат и полная
сетевая партия от торговли до записи очков уже работают. **Цель этой фазы:**
хозяин стола может посадить на любое пустое место компьютер, выбрать уровень
его игры — «новичок / игрок / мастер», и партия играется без третьего человека:
бот торгуется, сносит, вистует и ходит сам, с человеческими паузами.

## Что нужно сделать

1. **Модель**: в `GamePlayer` добавь `isBot Boolean @default(false)` и
   `botLevel String?` (значения нормализует движок, см. п. 2). Миграция.
   Бот — настоящая запись `User` с ником «Компьютер N» (nicknameKey уникален:
   подбирай номер или суффикс), поэтому сеанс, `GameResult` и переподключение
   работают без вилок. Итоги пишутся и ботам.
2. **Мозг бота** — чистый модуль `src/lib/preference/bot.ts` + `bot.test.ts`:
   `chooseAction(round, seat, level) → RoundAction`. Железные правила:
   - всегда из `legalMoves`; любое решение — **чистая функция состояния**,
     без случайности и таймеров (случайна только пауза планировщика);
   - тип `BotLevel = "NOVICE" | "PLAYER" | "MASTER"` + `normalizeBotLevel`
     по образцу `normalizeRuleset`; константа `BOT_DELAY = { minMs, maxMs }`.
   Поведение по уровням (семантику уточняешь сам, главное — различимость):
   - новичок: наивная оценка руки (тузы, длина масти), заказ только 6 при
     «на что-то», ход — случайная легальная карта, вист почти никогда;
   - игрок: снос по масти (короткие/мелкие), ход под старшего, козырь на
     сброс, вист при сильной руке;
   - мастер: оценка вероятных взяток (козырная длина + онёры), бьёт
     минимально достаточной картой, скидывает опасные, вистует и торгуется
     по расчёту; мизер объявляет только при чистой руке.
3. **Планировщик** — `src/server/bot-scheduler.ts`: после каждой рассылки
   `game:state`, если ход за ботом и партия PLAYING — таймер на случайную
   паузу из `BOT_DELAY`; перед применением перепроверяет, что ход всё ещё
   его; действие идёт через тот же `applyUserProposal` (тот же `game:action`,
   те же проверки). Один активный таймер на сеанс, снятие при финале партии.
4. **Посадка**: сокет-событие `game:bot-seat { seat, level }` — только
   хозяин, только в LOBBY, только на пустое место; создаёт User+GamePlayer,
   сеанс подхватывает состав (liftSession уже умеет), комната получает
   `room:state` + `game:state`. Опционально `game:bot-remove` (тот же лобби-
   режим, удаляет бота).
5. **Интерфейс**: на пустом месте (seat-plate) — кнопка «компьютер» для
   хозяина в лобби и выбор из трёх уровней; на табличке бота — бейдж
   «компьютер · мастер»; чип статуса не врёт про «за столом». В лобби-список
   столов боты попадают как игроки. Тексты интерфейса — по-русски.
6. **Тесты**: в стиле существующих — решения бота всегда легальны, уровни
   различимы на контрольных раздачах, полный цикл партии «человек стартовал —
   боты доиграли» через session-core (ходы человека подставляешь сам).

## Конвенции

- Server-authoritative: клиент только предлагает действия; бот — не исключение.
- TypeScript strict, стиль соседних файлов (двусловные комментарии по-русски),
  ESLint/TSC чисто; без новых зависимостей; ничего «за компанию».
- Незакоммиченные изменения в репо — работа предыдущих сессий, не откатывай.

## Definition of Done

- `pnpm typecheck && pnpm lint && pnpm test && pnpm build` — без ошибок.
- `scripts/bot-smoke.mjs`: стол с двумя ботами разных уровней, человек-сокет
  только стартует партию — боты доигрывают до `GameResult`, в логах нет
  `game:error`, места записаны.
- `pnpm dev` на `:3005`: хозяин сажает двух ботов с разными уровнями, играет
  партию против них; боты ходят с паузами, бейджи на местах, итог партии
  записан; перезапуск сервера посреди партии не ломает игру.
- Юнит-тесты: решения бота легальны и различимы по уровням.
